# עיצוב פנים קרוב לבית

אתר שבו המשתמש בוחר סגנון עיצוב ופלטת צבעים, ומקבל פריטים מתאימים מחנויות, ממוינים לפי המרחק מהבית.

## מה יש כרגע

- בחירת סגנון. כרגע פעיל רק "מודרני / מינימליסטי", ושאר הסגנונות מסומנים "בקרוב".
- בחירת פלטת צבעים מתוך חמש פלטות שמתאימות לסגנון.
- קביעת מיקום: איתור מיקום בדפדפן, או בחירת עיר מהרשימה.
- רשימת פריטים ממוינת מהקרוב לרחוק, עם סינון לפי קטגוריה ומרחק, כפתור לעמוד הפריט באתר החנות וכפתור ניווט לסניף הקרוב.
- הבחירות נשמרות בדפדפן לביקור הבא.

## חנויות מחוברות (דרך 1: קישור יוצא)

| רשת | סניפים | מה יש בקטלוג |
|---|---|---|
| הום סנטר | כל הסניפים מעמוד הסניפים של הרשת | רהיטים, תאורה, אחסון |
| ACE | סניפי ACE (בלי סניפי אוטודיפו בלבד) | ספות, כורסאות, שולחנות, תאורה |
| פוקס הום | כל הסניפים מעמוד הסניפים של הרשת | כריות, שטיחים, אגרטלים, תאורה |
| גולף & קו | סניפי גולף (בלי SABON) | כריות ואגרטלים |
| נלה | אולם התצוגה בראשון לציון | שולחנות סלון |

- **מוצרים:** כל פריט הוא מוצר אמיתי, עם קישור לעמוד המוצר ומחיר מהאתר. המחירים נבדקו ב-29.9.2026, והמחיר המוצג הוא המחיר באתר ביום הבדיקה, כולל מבצע אם היה.
- **תמונות:** אין עדיין. מוסיפים תמונה רק אחרי שהחנות אישרה, או כשהיא מגיעה מתוכנית שותפים. עד אז הכרטיס מציג את צבעי הפריט.
- **מרחק:** מחושב לסניף הקרוב של הרשת. אין מידע על מלאי בכל סניף, ולכן זה "הסניף הקרוב שמוכר את הרשת", לא "הסניף שבו הפריט במלאי".
- **קואורדינטות:** כשהרשת מפרסמת קואורדינטות (ACE, רוב סניפי גולף, נלה) השתמשנו בהן. בשאר הסניפים הכתובת הומרה לקואורדינטות דרך OpenStreetMap, ואם הכתובת לא נמצאה נלקח מרכז העיר. השדה `prec` בכל סניף מציין את המקור.
- **ניווט:** כפתור הניווט מחפש בגוגל מפות לפי שם הסניף והכתובת, ולא לפי הקואורדינטות. כך הוא מגיע לחנות עצמה.
- **איקאה:** עדיין לא מחוברת. האתר שלה חוסם גישה אוטומטית, ולכן אי אפשר לאמת מחירים. אפשר להוסיף פריטים ידנית אחרי בדיקה בדפדפן.

## הרצה

אין צורך בהתקנה. פותחים את `index.html` בדפדפן, או מפרסמים דרך GitHub Pages.

## איך מוסיפים תוכן

| מה | קובץ |
|---|---|
| סגנון או פלטת צבעים | `data/styles.js` |
| רשת או סניף | `data/stores.js` |
| פריט | `data/items.js` (הסבר על כל שדה מופיע בראש הקובץ) |
| עיר לרשימה | `data/cities.js` |

פריט חדש מקבל `storeId` של הרשת שמוכרת אותו, `url` של עמוד הפריט באתר החנות ו-`price` כפי שמופיע שם. כשמעדכנים מחירים, מעדכנים גם את התאריך בכותרת התחתונה ב-`index.html`.

## שלבים הבאים (תכנון)

1. **סגנונות נוספים**: סקנדינבי/בוהו, תעשייתי, קלאסי/כפרי.
2. **תמונות באישור**: לפנות לרשתות ולבקש אישור להציג את תמונות המוצרים. נלה מפעילה תוכנית שותפים למעצבים (10% עמלה).
3. **תוכניות שותפים (Affiliate)**: ייבוא אוטומטי של קובצי מוצרים מרשתות שותפים, עם עמלה על כל רכישה. דורש צד שרת קטן.
4. **העלאה עצמית של חנויות**: חשבון לחנות, טופס להעלאת פריטים וסניפים, ומסד נתונים (למשל Supabase). רק כך אפשר לדעת מה נמצא במלאי בכל סניף.

## הערה משפטית

מציגים שם מוצר, מחיר וקישור לעמוד המוצר, ומפנים לרכישה באתר החנות. תמונות מציגים רק באישור החנות או דרך תוכנית שותפים. לא סורקים אתרים אוטומטית (Scraping) בלי אישור: הנתונים הנוכחיים נאספו פעם אחת ונבדקו ידנית, ואין סורק שרץ באתר.
