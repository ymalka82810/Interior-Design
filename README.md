# עיצוב פנים קרוב לבית

אתר שבו המשתמש בוחר סגנון עיצוב ופלטת צבעים, ומקבל פריטים מתאימים מחנויות, ממוינים לפי המרחק מהבית.

## מה יש כרגע (גרסה בסיסית)

- בחירת סגנון. כרגע פעיל רק "מודרני / מינימליסטי", ושאר הסגנונות מסומנים "בקרוב".
- בחירת פלטת צבעים מתוך חמש פלטות שמתאימות לסגנון.
- קביעת מיקום: איתור מיקום בדפדפן, או בחירת עיר מהרשימה.
- רשימת פריטים ממוינת מהקרוב לרחוק, עם סינון לפי קטגוריה ומרחק, כפתור לעמוד הפריט באתר החנות וכפתור ניווט לסניף.
- הבחירות נשמרות בדפדפן לביקור הבא.

כל הפריטים והחנויות בקטלוג הם **לדוגמה בלבד**.

## הרצה

אין צורך בהתקנה. פותחים את `index.html` בדפדפן, או מפרסמים דרך GitHub Pages.

## איך מוסיפים תוכן

| מה | קובץ |
|---|---|
| סגנון או פלטת צבעים | `data/styles.js` |
| חנות או סניף | `data/stores.js` |
| פריט | `data/items.js` (הסבר על כל שדה מופיע בראש הקובץ) |
| עיר לרשימה | `data/cities.js` |

פריט חדש מקבל `storeId` של הסניף שמוכר אותו, ו-`url` של עמוד הפריט באתר החנות.

## שלבים הבאים (תכנון)

1. **סגנונות נוספים**: סקנדינבי/בוהו, תעשייתי, קלאסי/כפרי.
2. **תוכניות שותפים (Affiliate)**: ייבוא אוטומטי של קובצי מוצרים מרשתות שותפים, עם עמלה על כל רכישה. דורש צד שרת קטן.
3. **העלאה עצמית של חנויות**: חשבון לחנות, טופס להעלאת פריטים וסניפים, ומסד נתונים (למשל Supabase).

## הערה משפטית

מציגים רק מידע ותמונות שהחנות אישרה או שמגיעים מתוכנית שותפים, ומפנים לרכישה באתר החנות. לא סורקים אתרים אוטומטית (Scraping) בלי אישור.
